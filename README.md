# TeamForge Backend (Spring Boot)
Java 21 · Spring Boot 3 · Spring Security + JWT · JPA/Hibernate · MySQL

1. Edit `src/main/resources/application.properties` and set `spring.datasource.password` to your MySQL password
   (the database `team_formation_db` is created automatically).
2. Run: `mvn spring-boot:run`  (or run `TeamforgeApplication` from VS Code / IntelliJ).
3. API runs at http://localhost:8080
